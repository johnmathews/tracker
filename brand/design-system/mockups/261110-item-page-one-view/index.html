One page for an item, in the week and in Edit plan

Pressing an item's name opens its page, in the week and in Edit plan alike. The Edit and Add dialogs go, and Edit plan's pencil goes with them. The question is where the page puts the three things only the dialogs did: the name, Remove and Add. The dashed outline marks them on each picture.

What is the same in both options:

  • This week's plan comes first, then Notes, Details and Recent weeks. A type you have already arranged (Arrange sections) keeps its order.
  • In the week the page looks as it does today, plan first. Name, Remove and Add show only in Edit plan.
  • Fields save as you type, as they do now. There is no Save button. A new item is the exception: it exists only once you press Add exercise.
  • Remove asks first, with today's question: "Remove Kettlebell swings? It comes off this week's plan. Weeks with their own plan keep it, and its marks stay." Then the page goes back to Edit plan.
  • Add exercise in Edit plan opens the page empty, with Sets 1, Reps 1 and 3 times a week. Cardio and food work the same way.
  • Remove also stays in the row on Edit plan, as it is now.
  • Round 2: option B is off the page. Its Remove row moved into A.
