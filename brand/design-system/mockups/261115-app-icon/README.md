## Options

Each option draws a marked day with the DayMark card's own paths: the hand-drawn box, and the zigzag drawing or the Ticks set's tick. The tab icon follows the browser's theme. The home-screen icon is a single PNG, so it keeps the light colours on every wallpaper.

- **A.** The box in `ink` over the zigzag drawing in `pen` green, on paper (`canvas`). (Recommended: it is the first mark anyone makes in the app, so the icon is the product's own picture.)
- **B.** The same box with the Ticks set's tick in `pen` green. It is the sharpest at 16px, and the closest to today's ink tick.
- **C.** Stamped: the whole icon in `pen` green, the box and the tick in paper. It is the boldest on a home screen.

All three put `pen` outside a day's mark. The icon draws a marked day, so the green still means "done well". That is a call for John, because docs/brand.md §3 keeps `pen` to the marks.
