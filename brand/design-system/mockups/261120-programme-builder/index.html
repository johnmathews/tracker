Open question

2. How a value shows its shape, and how a field is left out

Each number in an activity can be one of three things. It can be a plain number, a value chosen at start, or a value that grows week by week. Times a week, Sets, Reps, Time, Distance and Weight all work this way. Some fields can also be left out: a plank has no weight. The card shown is Plank: 3 sets, a hold that starts at 30 s and grows 5 s every 2 weeks up to 90 s, and no weight.

Measure gains a third choice in every option: Reps, Time or Neither. A field that can be left out offers None. A field left out stays out of the saved programme.

A. One line per value, opened one at a time

Option A

Each value is a line: its name, then its shape in words, such as “30 s, +5 s every 2 weeks, up to 90 s” or “None”. Pressing a line opens it into the group that round 1 drew for Weight, and closes the one open before. Recommended: the card stays short, and every value reads as a sentence before it is opened.

C. A Grows switch on each field

Option C

Each value is a plain field with a Grows switch beside its name. Turning it on shows the increase under the field. The menu beside a field offers a value chosen at start. Weight left empty means none. The fields read like the app’s own exercise form. A value chosen at start and None are less visible, since each sits behind a menu or an empty box.

Open question

3. An exception week, opened

An exception week replaces some values for named weeks, such as a deload. It holds its weeks (any of 1 to 156), an optional label, and its values. A value is for every activity or for one, and each is a number or a percentage of the planned value. One activity’s own value beats the value for every activity. Both options open the exception in place, framed as an open activity card is. The example is Beginner 5×5’s deload: weeks 4 and 8, 3 sets and 90% of the weight, and the deadlift at 1 set.

A. Weeks typed as a list, values as rows

Option A

The weeks are typed as numbers with commas: “4, 8”. The values sit in groups, one for every activity and one per activity that has its own. Each row says what it changes: Set to a number, or % of planned. Recommended: it works the same for 8 weeks or 156, and each row reads as what it does.

B. Weeks pressed on a grid of numbers, values in a table

Option B

Each week is a number to press. The values sit in a table: a row for every activity and one per activity, and a column per field. A cell holds a number, or a percentage such as 90%, and an empty cell keeps the plan. The table shows every value at once. A 156-week programme shows 156 numbers, and the table scrolls sideways on a phone.
