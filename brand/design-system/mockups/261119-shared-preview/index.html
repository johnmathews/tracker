Shared library: preview before copying

How anyone looks at a shared programme's plan before copying it (#88, after John tried the build). Everything else on the Library tab stays as it is: the section From the shared library (K171), and Copy to library's question and its Added to library state (K172).

Today is Thu 19 Nov 2026. The shared library holds Strength 5×5, Couch to 5K and Desk mobility. The grid is the server's (P4), at the programme's own values, with weeks by number: a copy takes its own values and start day when it is started. No option adds a colour.

One question · any user

1. Preview, on a shared row

Each shared row gains Preview (secondary, Lucide eye) before Copy to library. Folded, the two sit side by side. What Preview opens is the question.

A. The plan, opened in place

Option A

Preview opens the row in place, framed in 2px ink, as Preview and start does on your own programmes (K147): a line, then the ProgrammeGrid week by week. Close and Copy to library (primary) end it, and Copy asks first, as now. One row opens at a time. Recommended: it is the look the Library already uses, so a programme reads the same before and after the copy.

B. As A, with each activity's notes and link

Option B

The same frame, and under the grid each activity with its notes and link, as Publish's preview lists them (“No notes.” where there are none). It shows how to do each one before the copy. It makes the frame about twice as tall on a phone.

C. A Dialog

Option C

Preview opens a Dialog titled with the programme's name: the facts, the description, the grid, and each activity's notes and link. Close and Copy to library (primary) sit at its foot. The list stays as it was behind it. It is a second way of showing a programme, beside the Library's in-place one.
