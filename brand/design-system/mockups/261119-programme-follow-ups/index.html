1. Restart and Re-open on an ended run

Today an ended run's overview shows its grid and no controls. The server can already do two things with it. Restart starts a new tracker from week 1. Re-open carries on a run that End programme stopped part way. Re-open fits only a run ended early; a run that ran to its last Sunday can only be restarted. A run with an end set for a later day is still running, so it keeps its normal controls.

Each option is drawn in three states: (i) ended early, (ii) ran to its end, (iii) still running with an end on a later day. Then the dialogs its buttons open, in the ChangeSheet's two steps. Each overview is trimmed to its head, Back squat's row of the grid over four weeks, and the buttons; the back link is left out, and the tabs too where nothing sits by them.

A. Two buttons where the controls sit

Option 1A

An ended run gets Re-open programme (only when it ended early) and Restart from week 1, where the controls row sits. A running run with a later end swaps End programme for Cancel the end. Each opens a ChangeSheet in two steps. Step 1 asks what the server needs, in the sheet's own fields: for Re-open, From (a date, today or later) and Reason; for Restart, Name (the old name to start with) and Starts (a date, today or later). Step 2 is the server's preview, then the confirm. Option B draws a step 1.

The overview, three states

Re-open programme, from state (i): step 2, the preview

Restart from week 1, from state (i) or (ii): step 2, the preview

Cancel the end, from state (iii): the re-open's preview, from the end's own day
